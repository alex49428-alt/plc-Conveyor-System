# PLC Conveyor System – Siemens TIA Portal

**Industrial Automation | PLC Programming | Ladder Logic | Simulation**

## Project Overview

This project focuses on the design and simulation of an automated conveyor belt system using Siemens PLC technology and TIA Portal.

The objective is to develop a structured PLC control program that demonstrates fundamental industrial automation concepts, including sequential control, motor control, sensor monitoring, operating modes, alarms, and fault handling.

**Project status:** In development.

## Objectives

- Develop PLC logic using Ladder Diagram (LAD).
- Implement manual and automatic operating modes.
- Control a conveyor motor using simulated inputs and outputs.
- Detect and count products using a sensor.
- Implement start, stop, and fault-handling logic.
- Validate system behavior through simulation and functional tests.
- Document the control sequence, I/O assignment, and test results.

## Technologies

- **PLC:** Siemens SIMATIC S7-1200
- **Engineering software:** TIA Portal V17–V19
- **Programming language:** Ladder Diagram (LAD)
- **Simulation:** S7-PLCSIM, subject to installed version compatibility
- **Documentation and version control:** GitHub

## System Description

The conveyor system is intended to transport products along a production line. A PLC will process operator commands and sensor signals to control the conveyor motor and monitor the system's operating conditions.

The planned control functions include:

- Start and stop commands.
- Manual and automatic operation.
- Product detection and counting.
- Motor status monitoring.
- Fault detection and alarm indication.
- Defined conditions for starting, stopping, and resetting the system.

These functions will be implemented and verified progressively.

## Validation and Testing

The project will include functional tests to verify:

- Correct startup and shutdown behavior.
- Manual and automatic mode operation.
- Product detection and counting.
- Response to stop commands and simulated faults.
- Correct operation of interlocks and reset conditions.

Test results and simulation evidence will be added as development progresses.
